# Difficulty Calibration Reference

本文件为 CET Skill 各模块提供**可量化、可自检**的难度硬指标。生成题目后，模型须对照此表逐项验证，确保难度匹配目标等级。

---

## 一、词汇难度指标

### CET-4 词汇要求

- 核心词汇 80%+ 应在 CET-4 大纲词表范围内（约 4,500 词）
- 超纲词占比 ≤ 5%，如使用须通过上下文可推断词义
- 避免学术期刊级低频词（如 phenomenon, paradigm, ubiquitous 等仅在 CET-6 出现）

### CET-6 词汇要求

- 须包含 15–25% 的 CET-6 级别词汇（约 6,000 词表内但超出 CET-4 范围）
- 典型 CET-6 级词汇示例：substantial, implication, contend, undermine, disproportionately, warrant, reconcile, offset, consensus, plausible, empirical, underscore
- 允许 3–5% 的超纲词汇，用于测试语境猜词能力（选词填空和仔细阅读的词义题）

### 自检清单

生成阅读/翻译/写作材料后，检查：
- [ ] CET-4：是否过度使用了 CET-6 级低频词？（是 → 降级词汇）
- [ ] CET-6：是否只用了 CET-4 基础词？（是 → 增加难度词汇，至少 5 个 CET-6 级词）

## 二、句法复杂度指标

### 量化参考

| 指标 | CET-4 | CET-6 |
|------|-------|-------|
| 平均句长 | 14–20 词/句 | 20–30 词/句 |
| 复合句占比 | 30–50% | 50–70% |
| 从句层级 | 1–2 层 | 2–4 层 |
| 非谓语结构 | 现在分词/过去分词/动名词 | 独立主格、分词完成式、不定式完成式 |
| 特殊句式 | 基础定语从句、状语从句 | 虚拟语气、倒装、强调、同位语从句、名词性从句嵌套 |

### 句法多样性要求

- CET-4：简单句 + 基础复合句（because/although/which/who）+ 少量非谓语
- CET-6：需包含至少 3 种以下结构：
  - 虚拟语气（If it were not for... / Had it not been...）
  - 倒装句（Not only does... / Only by... can...）
  - 长插入语/同位语
  - 让步+转折的复合逻辑（While... it is also true that...）
  - 名词化结构（the implementation of... / the emergence of...）

### 自检清单

生成后抽样 3 个句子验证：
- [ ] CET-4：平均句长是否在 14–20 词？（超过 → 拆分长句）
- [ ] CET-6：是否有足够的从句嵌套和非谓语结构？（不足 → 合并句子，增加修饰层）
- [ ] CET-6：是否避免了"全文简单句 + 一两个长句"的不均匀分布？（是 → 均匀分布复杂度）

## 三、信息密度指标

### 段落信息量

| 指标 | CET-4 | CET-6 |
|------|-------|-------|
| 每段主要信息点 | 1–2 个 | 2–4 个 |
| 信息展开方式 | 论点→解释→例证 | 论点→让步→限定→论证→例证 |
| 段落间逻辑关系 | 并列/递进 | 让步/对比/因果链/限定 |

### 文本"水分"控制

- CET-4：允许少量重复或过渡句，但不超过全文 10%
- CET-6：严格避免语义重复，每句话必须推进新信息或加深论证
- 检测方法：删除每个句子后，检查是否丢失了不可恢复的信息。如果删除后段落意思不变 → 该句是水分

### 自检清单

- [ ] 每段是否能用一句话概括其不可替代的信息增量？
- [ ] CET-6：是否有"为凑字数而存在"的句子？（是 → 删除或合并）

## 四、推理深度指标

### 题目推理层级

| 层级 | 说明 | 适用 |
|------|------|------|
| L0 定位 | 原文直接有对应句，几乎不改写 | CET-4 基础题 |
| L1 同义改写 | 原文换词/换句式表达 | CET-4 主力 / CET-6 基础题 |
| L2 概括推断 | 需要综合多句信息才能得出 | CET-6 主力 |
| L3 隐含推理 | 需要推断作者未明说的立场/意图/因果 | CET-6 难度题 |

### 题目类型难度分布

一套 CET-4 仔细阅读（10 题）应有：
- 3–4 题 L0/L1（定位+改写）
- 4–5 题 L1/L2（同义改写+概括）
- 1–2 题 L2（综合推断）

一套 CET-6 仔细阅读（10 题）应有：
- 2–3 题 L1（基础改写）
- 4–5 题 L2（概括推断）
- 2–3 题 L3（隐含推理）

### 自检清单

生成题目后，逐题标注推理层级：
- [ ] CET-4：L0 题是否过多（超过 5 题）？（是 → 将部分 L0 升级为 L1）
- [ ] CET-6：是否全是 L1 题？（是 → 必须增加 L2/L3 题）

## 五、干扰项质量指标

### 干扰项可信度分级

| 级别 | 特征 | 适用 |
|------|------|------|
| G1 明显无关 | 和文章话题无关，一眼排除 | 不应用于任何 CET 题目 |
| G2 话题相关但逻辑无关 | 词对但逻辑不对 | CET-4 至少 1 个/题 |
| G3 部分正确但范围/主体/条件错 | 需要仔细比对才能排除 | CET-4 主力 / CET-6 基础 |
| G4 几乎正确但有细微偏差 | 需要精确理解才能排除 | CET-6 主力 |
| G5 合理但非最佳 | 另一个选项也 "对"，但本文更支持 D | CET-6 主旨/推断题 |

### 干扰项分布要求

每道 CET-4 选择题 4 个选项中：
- 1 个正确选项
- 至少 1 个 G3 级干扰项
- 不允许出现 G1 级干扰项

每道 CET-6 选择题 4 个选项中：
- 1 个正确选项
- 至少 2 个 G3/G4 级干扰项
- 主旨/推断题至少 1 个 G5 级干扰项

### 自检清单

逐题检查每个干扰项：
- [ ] 是否有 G1 选项？（有 → 重写，加入部分正确元素）
- [ ] CET-6：干扰项是否与正确选项在长度/语气/用词上过于不同？（是 → 平衡风格）
- [ ] CET-6：是否有"合理但非最佳"的 G5 干扰项？（没有 → 为主旨/推断题增加）
- [ ] 正确选项是否比干扰项更长或更"温和"？（是 → 需平衡）

## 六、文本真实感指标

### 文章风格要求

| 特征 | CET-4 | CET-6 |
|------|-------|-------|
| 来源感 | 改写过的说明文/议论文 | 类似原文的媒体/学术文章 |
| 论点显性度 | 首段或尾段可找到主旨 | 需通读全文才能把握完整论点 |
| 衔接词密度 | 适量使用（however/therefore/for example） | 减少显性衔接词，靠语义推进 |
| 作者立场 | 直接表达 | 通过措辞和框架隐含呈现 |

### CET-6 必选文本特征

CET-6 阅读文章须至少包含以下 2 项：
1. 让步/限定：acknowledge 一个观点再论证其不足
2. 多重因果：不只有 A→B，还有 C 的中介或调节作用
3. 研究引用：提及某研究/调查/数据但非简单罗列
4. 对比视角：呈现两种立场或两种解释
5. 反直觉发现：结论与常识预期不完全一致

### 自检清单

- [ ] CET-6 文章："五段式 AI 论文" 痕迹是否过重？（是 → 打乱结构，减少标语式段首句）
- [ ] CET-6 文章：是否至少包含 2 项 "必选文本特征"？（不足 → 重写）
- [ ] CET-4 文章：是否过于幼稚或简单？（是 → 增加适度的信息量但不越级）

## 七、生成前难度锚点（必做）

生成**任何** CET-4 或 CET-6 题目之前，先自行列出 3 个难度锚点——即本道题的难度来源：

> 本题难度锚点：
> 1. {锚点 1：如 "正确选项的 evidence 跨两段，需要综合理解"}
> 2. {锚点 2：如 "干扰项 B 使用了原文词汇但改变了逻辑关系"}
> 3. {锚点 3：如 "作者态度不是简单的支持/反对，而是谨慎乐观"}

如果列不出 3 个具体锚点，或锚点过于空泛：**不要生成，先重新设计题目方向**。

## 八、生成后难度自检（必做）

生成后，逐项勾选：

### CET-4 检查
- [ ] 词汇：80%+ 在 CET-4 词表范围
- [ ] 句长：平均 14–20 词
- [ ] 信息：每段 1–2 个主要信息点
- [ ] 推理：L1 改写题为主力，至多 2 题 L2
- [ ] 干扰项：无 G1 明显无关项，至少 1 个 G3
- [ ] 文本感：文章比高中课本略难但可通读

### CET-6 检查
- [ ] 词汇：15–25% CET-6 级词汇，有可测的语境词义题
- [ ] 句长：平均 20–30 词，含 3+ 种复杂句式
- [ ] 信息：每段 2–4 个信息点，无水分句
- [ ] 推理：L2/L3 推理题占 50%+
- [ ] 干扰项：至少 2 个 G3/G4 级，主旨题有 G5
- [ ] 文本感：读起来像媒体文章而非教科书范文
- [ ] 必选特征：包含至少 2 项 "CET-6 必选文本特征"
